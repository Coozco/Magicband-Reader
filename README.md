This setup uses a Raspberry Pi Pico and a Arduino Nano. Along with a PN532 RFID reader, I2S 3W Class D Amplifier Breakout - MAX98357A, 8ohm 1watt mini oval speaker, and a high density RGB 3 pin LED strip. Circuitpy 9.2.4 is installed on the pico. Power the magicband reader through the Raspberry Pi.

Included is the files to upload to the raspberry pi after circuitpy is installed as well as the .ino file for the arduino nano.

Also included are a modified circuitboard holder (hot glue the arduino to it) and a deeper light ring if you do not get the arduino side profile neopixle strip.

Follow the circuit diagram to wire it up.
